# Source and license notice

`noble-rei` is an independent reimplementation and reproducibility harness for the
method described in Connor Hill, *The complete set of noble polyhedra* (2026).

The public reference implementation is:
`Plasmath/noble-tools-revised`, licensed GNU GPL v3.

This repository is distributed under GPL-3.0-or-later. The `upstream-run` adapter does
not vendor or modify the upstream repository; it executes a separately supplied checkout.
